# calendar-disc
Calendrier perpétuel ( avec jours de la semaine) de 1844 à 2118 
Objectif du dispositif
Permettre de déterminer, pour n’importe quelle date entre 1844 et 2118 :

le jour de la semaine

la position dans le cycle hebdomadaire

la structure du mois (longueur, position des jours)

la correspondance mécanique entre les deux disques

Le tout sans calcul, uniquement par alignement mécanique.

🧩 Principe général
Le système repose sur deux disques imprimables :

1. Le disque principal
Il contient :

une spirale d’années allant de 1844 à 2118

une couronne de 28 secteurs (4×7), correspondant aux jours de la semaine

les initiales des jours, orientées haut vers le centre

les années, orientées bas vers le centre

une géométrie millimétrique permettant un alignement précis

La spirale encode la progression du calendrier :
chaque année avance d’un secteur, et les années bissextiles sont gérées par une règle mécanique élégante :

Insertion d’une case vide AVANT chaque année bissextile  
(ce qui compense le décalage du calendrier réel)

Cette règle est unique et ne se retrouve dans aucun disque existant.

2. Le disque secondaire
Il affiche :

les mois, répartis en colonnes verticales

les jours du mois (1–31), répartis en 7 colonnes

une orientation radiale cohérente

une gestion visuelle des doublons (JAN(bis), FEV(bis))

une synchronisation parfaite avec les 28 secteurs du disque principal

Les deux disques s’assemblent par un axe central, permettant une lecture directe.
